# 10 — UAM app manifest

Validate a Universal App Manifest (UAM v1) before deploy or AI builder writes.

## Run

```bash
npm run recipe:10-uam-app
```

Uses `appManifestSchema` from `@agentstack/sdk/manifest` (same rules as `validateAppManifest` on the main SDK export).
