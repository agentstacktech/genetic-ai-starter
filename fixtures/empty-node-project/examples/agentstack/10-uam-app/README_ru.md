# 10 — UAM app manifest

Валидация Universal App Manifest (UAM v1) перед деплоем или записью из AI builder.

## Запуск

```bash
npm run recipe:10-uam-app
```

`appManifestSchema` из `@agentstack/sdk/manifest` (эквивалент `validateAppManifest` в основном экспорте SDK).
