# 08 — Capability task

Запуск comfort-задачи через `runTaskCapability` (`@agentstack/sdk/capability-tasks`).

## Переменные

- `AGENTSTACK_PROJECT_ID` — если без входа
- `AGENTSTACK_EMAIL` / `AGENTSTACK_PASSWORD` — необязательно

## Запуск

```bash
npm run recipe:08-capability-task
```

Регистрируется порт `recipe.demo.echo`. Id задач: `sdk.getModuleCatalog().tasks`.
