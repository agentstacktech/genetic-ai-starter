# 09 — RAG search

MCP-действие `rag.search` для семантического поиска.

## Переменные

- `AGENTSTACK_API_KEY`
- `AGENTSTACK_PROJECT_ID`
- `RAG_COLLECTION_ID` — для живого вызова
- `RAG_QUERY` — текст запроса
- `RAG_TOP_K` — по умолчанию `3`

## Запуск

```bash
npm run recipe:09-rag
```

Без `RAG_COLLECTION_ID` рецепт только документирует payload.
