# 07 — Hosting

Публикация HTML через `sdk.hosting.quickStart` (`sdk.hosting.gen2`).

## Переменные

- `AGENTSTACK_EMAIL` / `AGENTSTACK_PASSWORD`
- `AGENTSTACK_PROJECT_ID`
- `HOSTING_BUCKET` — сегмент пути (по умолчанию `sdk-recipe-demo`)
- `HOSTING_DRY_RUN=1` — только auth/scope
- `HOSTING_PUBLISH=0` — без публикации

## Запуск

```bash
npm run recipe:07-hosting
```
